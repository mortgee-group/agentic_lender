Project information

About AL-Web

A frontend prototype for a university software development group project.

Project Overview

AL-Web is the user-facing interface of an AI-assisted property valuation platform. It enables a user to submit property information, request an estimate and view explanations of the reported result.

Frontend Technologies

UI frameworkReact
LanguageTypeScript
API integrationREST / JSON
Current stateInteractive mockup

Conceptual flow, subject to confirmation with the rest of the project team.

Explanation

A separate ledger component may record valuation activity, depending on the agreed backend interface and data flow.

Prototype Scope

Demonstrates navigation, property form validation, a synthetic valuation result, a template explanation and in-session valuation history. Authentication, live APIs, backend persistence and machine-learning inference are intentionally excluded.
